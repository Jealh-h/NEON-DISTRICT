# 霓虹特区 · NEON DISTRICT

一款基于 **React 19 + TypeScript + Phaser 4 + Zustand + Tailwind CSS v4** 打造的俯视角赛博朋克像素风 GTA 式开放世界动作沙盒游戏。

---

## 一、 游戏模式

1. **自由沙盒（开放世界）**
   - 自由漫游 `3200 × 2400` 像素五大连通城区，承接 7 项主线/支线委托、响应 **6 类城市动态随机事件**、开启警用【治安追缉】悬赏、收集 10 枚霓虹数据芯片（集齐额外奖励 `$1,000`），在实时 **昼夜循环与动态天气** 中与 1★–5★ 阶梯式特区警队展开对抗与甩脱追捕。
2. **无尽杀怪（浪潮生存 + 肉鸽强化）**
   - 迎战不断升级的失控义体狂徒、远程猎杀无人机、重装生化暴君与每 5 波登场的机甲 Boss「铁幕机甲 · 屠戮者」。
   - **每清完 3 波（第 3/6/9... 波）触发「战术强化三选一」肉鸽模块空投**（10 种可叠加强化词条），配合连击倍率、武器过载掉落，以及专属的 **战斗机甲空降、战术防弹护甲、自动激光哨戒炮、轨道离子轰炸与空投主战坦克** 支援。
3. **极速狂飙（环城竞速）**
   - 驾驶高性能跑车穿越 14 个全城检查点，串联跨河大桥、东岸盘山弯道、铬铁涡轮加速带与飞跃跳台，支持本地最佳圈速纪录存档与高额夺冠奖金。

## 二、 开放世界与地形地貌

地图采用高精细度赛博像素风绘制，涵盖五大连通城区与多样化自然及城市场景地貌：

- **五大城区**：
  - **霓虹广场**（中心枢纽商业区：枢纽行动终端、赛博集团、数据交易所、天际公寓安全屋、街机俱乐部、义体诊所、字节便利店 24/7、狐狸拉面馆、广场科技坊军械库、特区警署 NCPD、脉冲夜店、广场改装车库）
  - **滨河生态公园**（南区水岸：翠水湾、湖心木栈桥、樱花/秋叶/翡翠林地、霓虹竞技场）
  - **苍穹山脉**（东北高地：雪原北峰、云巅冰原、赤岩荒漠、黑曜活火山与熔岩流、苍穹山顶观景台与雷达站）
  - **暗港码头**（西南港口：远洋货仓、暗港黑市地下军械、A/B 区货柜、黄金海滩与热带棕榈、离岸暗港灯塔岛、停靠货轮与快艇）
  - **铬铁工业区**（东南工业：铬铁重工涡轮车坊、聚变供电厂、散热冷却塔、极速赛事总部、涡轮高速加速直道）
- **动态世界生态（V1.1）**：
  - **昼夜循环与动态天气**：特区时间随 **破晓清晨 / 霓虹白昼 / 赛博黄昏 / 霓虹深夜** 流转；随机切换 **晴朗夜空 / 霓虹暴雨 / 电磁雷暴 / 赤岩沙暴** 视觉氛围并真实作用于警队搜敌视野（最高 `-38%`）与载具路面抓地力（湿滑漂移）。
  - **6 类城市动态随机事件**：自由沙盒模式下全城自动刷出 **街头持械抢劫、黑帮街头火拼、运钞车武装押运、暗网高速悬赏犯、军工重装运输队、失控赛博义体疯子**，小地图与战术全图实时标出脉冲定位信标，平息或劫掠可赢取高额现金、经验值与三方声望。
- **交互式城市场景**：
  - **可破坏/可互动道具**：黑客 ATM 提款机（按 `E` 提取现金）、红油桶（射击或高速撞击引爆连锁爆炸）、补给木箱（击碎掉落现金或弹药）、消防栓（击破喷射高压水柱）。
  - **街区生活与设施**：红绿交通灯、蒸汽井盖、行人 NPC 对话/受惊逃散、自动行驶的社会车流、5 座特技飞跃跳台、9 组涡轮加速带、车载电台系统（3 套赛博合成波频道 + 静音）。
  - **安全屋与本地存档**：购置「天际公寓」安全屋后可免费回满状态、立即消星并将现金/任务/武器/护甲/车辆改装/角色成长与义体声望数据写入本地 `localStorage`（v2 向后兼容）。

1. **脉冲手枪 MK-II**（制式配枪，无限微核供能）
2. **霓虹冲锋枪 V-9**（高射速连射弹幕压制）
3. **等离子霰弹枪 M8**（5 发粒子散射，近距爆发与击退）
4. **电磁突击步枪 X-47**（中远距离高精度高初速卡宾枪）
5. **烈焰喷射器 PYRO-6**（扇形高热火浪持续灼烧清群）

7. **微型火箭筒 RPG-77**（高爆微火箭，大范围冲击波溅射摧毁载具与机甲）

## 五、 角色成长、赛博义体与三方声望（V1.2）

随时按 **`C`**（或点击左上角 `[C] 角色/义体`）打开角色构建面板：

- **角色等级与 4 大技能树**：战斗、任务、事件与收集可获取 EXP 升级并获赠技能点，自由加点 **战斗专家 / 机械专家 / 黑客专家 / 生存专家**（每系 Lv.1–Lv.4）。黑客 Lv.2 解锁主动技 **`[H]` 警讯干扰**，可暂时屏蔽 1★–3★ 警用雷达追踪。
- **5 部位赛博义体植入**：在面板内直接购置安装 **光学扫描仪 / 动力战斗义肢 / 机动伺服义腿 / 神经脊椎插件 / 战术计算核心**（MK.I–MK.III），高阶义体受对应阵营声望解锁限制。
- **三方阵营声望**：积累 **街头威望 / 黑客声望 / 执法声望** 晋升称号阶位并解锁高阶义体权限。

- **战斗机甲空降**：
  - **泰坦重装机甲 TITAN-X（`$450`）**：450 机甲护盾，踏步碾压小型敌军，主武器为双联高频等离子炮；按 **`空格`**（或触屏技能键）释放 **5 枚肩部集束火箭齐射**（6 秒冷却）。

- **战术防弹护甲（`$120`）**：补充 `+50` 护甲（上限 `100`），吸收 **75%** 生命伤害（沙盒与无尽模式均可购买，也可在街头拾取护甲包）。

## 七、 GTA 式警匪通缉与街头犯罪

- **1★–5★ 阶梯通缉体系**：
  - **1★–2★**：街头巡逻警员与巡逻警车出动追击。
  - **3★**：高速拦截警车加入全城围捕。
  - **4★**：武装警用直升机升空锁定并开火扫射（击落奖励 `$280`）。
  - **5★**：NCPD 特警重装运兵车与重装主战坦克出动拦截（击毁奖励 `$450`）。
- **多种消星方式**：脱离警力视线躲藏至逃脱进度条满、激活黑客技能 `[H]` 警讯干扰、前往车库购买隐匿喷漆、在脉冲夜店买通线人、回私人安全屋休整，或拾取街头 **警星贿赂道具**（`-1★`）。
- **治安追缉悬赏（Vigilante）**：驾驶警车或特警运兵车时按 `E` 触发逃犯追缉，小地图与战术全图会以金红菱形标出逃犯载具位置，摧毁即可赢取递增悬赏奖金与执法声望。

## 八、 操作指南

### 键盘与鼠标（桌面端）
- **步行移动 / 全向驾驶**：`W A S D` 或 `方向键`
- **瞄准与开火（步行 / 机甲 / 车载扫射 / 坦克旋塔主炮 / 直升机机炮）**：`鼠标瞄准 + 左键` 或 `J`
- **切换武器**：`Q` 或数字键 `1`–`7`
- **机甲专属技能 / 载具手刹**：`空格 (Space)`
- **载具氮气加速**：`Shift`
- **上车 / 劫车 / 下车**：`F`
- **交互 / 进入地标 / 开启治安追缉**：`E`
- **随身军械库与机甲支援面板**：`B`
- **角色技能树 / 义体植入 / 声望面板**：`C`
- **黑客警讯干扰（需黑客 Lv.2）**：`H`
- **切换车载电台**：`R`
- **打开战术全图**：`M`
- **暂停 / 切换模式菜单**：`Esc`

### 触屏端（移动/平板自适应双摇杆）
- **左摇杆**：步行移动 / 全向驾驶
- **右摇杆**：360° 瞄准与自动连发开火（同时支持步行、车载扫射、坦克炮塔旋转开火与直升机机炮）
- **右侧功能键**：随身军械/机甲、机甲技能、切枪、交互/改装/治安追缉、上车/下车、电台、刹车与氮气加速
