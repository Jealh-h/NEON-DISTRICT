# 霓虹特区 · NEON DISTRICT

一款基于 **React 19 + TypeScript + Phaser 4 + Zustand + Tailwind CSS v4** 打造的俯视角赛博朋克像素风 GTA 式开放世界动作沙盒游戏。

---

## 一、 游戏模式

1. **自由沙盒（开放世界）**
   - 自由漫游 **`4800 × 3584` 像素七大连通城区**，承接 **9 项主线/支线委托**、响应 **6 类城市动态随机事件**、开启警用【治安追缉】悬赏、收集 **14 枚霓虹数据芯片**（集齐额外奖励 `$1,500`）。
   - **立体沙盒探索循环**：骇入 **7 座城区信号塔**（解锁对应磁悬浮车站并揭露加密金库坐标）、发现并乘坐 **7 座磁悬浮快传站点**（点击战术全图即可瞬时跨区传送）、借助声呐探测破解 **8 座加密秘密金库**、清剿 **4 座黑帮重兵据点**、挑战全城 **7 座特技飞跃跳台并刷新最远飞跃距离纪录**，并可在全图任意位置点击放置 **自定义 GPS 航标**。
2. **无尽杀怪（浪潮生存 + 肉鸽强化）**
   - 迎战不断升级的失控义体狂徒、远程猎杀无人机、重装生化暴君与每 5 波登场的机甲 Boss「铁幕机甲 · 屠戮者」。
   - **每清完 3 波（第 3/6/9... 波）触发「战术强化三选一」肉鸽模块空投**（10 种可叠加强化词条），配合连击倍率、武器过载掉落，以及专属的 **战斗机甲空降、战术防弹护甲、自动激光哨戒炮、轨道离子轰炸与空投主战坦克** 支援。
3. **极速狂飙（环城竞速）**
   - 驾驶高性能跑车穿越 **16 个全城检查点**，串联广场核心大道、量子科技环道、苍穹雪峰盘山道、霓虹星港跑道、铬铁涡轮加速直道、滨河跨海大桥与暗港海岸线，支持本地最佳圈速纪录存档与高额夺冠奖金。

## 二、 开放世界、智能机制与地形地貌

地图采用程序化 Tiled 图块合图与赛博像素风绘制，涵盖 **150 × 112** 瓦片、七大连通城区、128px 四车道主干道与 6 座跨河跨海大桥：

- **七大城区（4800 × 3584）**：
  - **霓虹广场**（中心枢纽商业区：枢纽行动终端、赛博集团、数据交易所、天际公寓安全屋、街机俱乐部、义体诊所、字节便利店 24/7、狐狸拉面馆、广场科技坊军械库、特区警署 NCPD、脉冲夜店、广场改装车库）
  - **量子科技园**（西北高新研发区：量子超算核心、生物神经实验室、量子磁悬浮站与数据塔台）
  - **苍穹山脉**（东北高地：雪原北峰、云巅冰原、赤岩荒漠、黑曜活火山与熔岩流、苍穹山顶观景台与雷达站）
  - **暗港码头**（西南港口：远洋货仓、暗港黑市地下军械、A/B 区货柜、黄金海滩与热带棕榈、离岸暗港灯塔岛、停靠货轮与快艇）
  - **滨河生态公园**（南区水岸：翠水湾、湖心木栈桥、樱花/秋叶/翡翠林地、霓虹竞技场）
  - **铬铁工业区**（东中工业：铬铁重工涡轮车坊、聚变供电厂、散热冷却塔、极速赛事总部、涡轮高速加速直道）
  - **霓虹星港**（东南航空航天港：超音速起降跑道、星港机库改装站、星港货运终端与飞跃跳台）
- **智能城市模拟与 AI 行为**：
  - **智能交通流**：社会车辆遵循十字路口红绿灯信号停走、预判前方车辆减速跟车、侦测障碍自动变道绕行，并在附近发生枪战或爆炸时触发紧急加速逃逸。
  - **战术级警队 AI**：巡逻/围捕警车覆盖 4 条全城环线，追击时基于玩家速度矢量进行 **提前量预判拦截（Predictive Lead）** 与 **双翼钳形包抄（Pincer Flanking）**，并在高通缉等级优先在玩家前进路线上方部署增援。
  - **自适应市民 NPC**：16 名分布于七大城区的赛博居民会感知天气变化调整步行节奏、随当前天气/通缉等级/信号塔同步度给出实时台词，并在高速车辆逼近轨迹时向垂直侧向紧急闪避。
- **动态世界生态与明亮昼夜视觉**：
  - **高可读性昼夜循环与动态天气 + WebGL 后期处理滤镜**：默认以 **10:30 霓虹白昼 · 晴空霓虹** 开局，路面与人行道经过高亮对比优化，夜晚与雨雾滤镜更加通透柔和；时间随 **破晓清晨 / 霓虹白昼 / 赛博黄昏 / 霓虹深夜** 流转，动态切换 **晴空霓虹 / 霓虹暴雨 / 赛博酸雨 / 霓虹浓雾 / 电磁雷暴 / 赤岩沙暴**，通过 Phaser 4 WebGL 滤镜实时调整色彩分级并影响警队视野与载具抓地力；可按 **`T`** 或点击顶部气象条随时切换体验。
  - **6 类城市动态随机事件**：自由沙盒模式下全城自动刷出 **街头持械抢劫、黑帮街头火拼、运钞车武装押运、暗网高速悬赏犯、军工重装运输队、失控赛博义体疯子**，小地图与战术全图实时标出脉冲定位信标，平息或劫掠可赢取高额现金、经验值与三方声望。
- **交互式城市场景与任务追踪**：
  - **任务与自定义 GPS 航标系统**：右上角任务追踪器实时计算距离与方向箭头；在战术全图（`M`）任意位置点击即可放置或取消自定义 GPS 航标，且小地图采用 **以玩家为中心的战术雷达视口**。
  - **可破坏/可互动道具**：黑客 ATM 提款机（按 `E` 提取现金）、红油桶（引爆连锁爆炸）、补给木箱、消防栓（高压水柱）、7 座特技飞跃跳台、涡轮加速带、车载电台系统（3 套赛博合成波频道 + 静音）。
  - **安全屋与本地存档**：购置「天际公寓」安全屋后可免费回满状态、立即消星并将现金/任务/武器/护甲/车辆改装/信号塔/金库/地铁解锁/据点/角色成长/造物台资源与建筑进度及自定义航标写入本地 `localStorage`。

## 七、 GTA 式警匪通缉（宽容怀疑值缓冲 + 合法交战豁免）

- **宽容怀疑值缓冲与冷却**：
  - 街头轻微碰撞路人、低速刮蹭或偶尔试枪不会立刻触发警星，而是先累积 **怀疑值（0–100，脱战后快速衰减）** 并弹出警告提示；怀疑值满或重大犯罪时才升级为 1★，且同类行为拥有冷却防抖。
  - **合法交战火线豁免**：在清剿黑帮据点、应对城市动态随机事件、挑战泰拉瑞亚世界 Boss 或开火采矿期间开火，NCPD 将豁免开枪惊扰判定，可放手激战。
- **1★–5★ 阶梯通缉体系与快速甩脱**：
  - **1★–2★**：街头巡逻警员与巡逻警车出动追击。
  - **3★**：高速拦截警车加入全城围捕。
  - **4★**：武装警用直升机升空锁定并开火扫射（击落奖励 `$280`）。
  - **5★**：NCPD 特警重装运兵车与重装主战坦克出动拦截（击毁奖励 `$450`）。
- **多种消星方式**：缩短的脱战逃脱倒计时（约 8 秒即可甩脱）、激活黑客技能 `[H]` 警讯干扰、前往车库购买隐匿喷漆（降价至 `$180`）、在脉冲夜店买通线人（`$240`）、回私人安全屋休整，或拾取街头 **警星贿赂道具**（`-1★`）。
- **治安追缉悬赏（Vigilante）**：驾驶警车或特警运兵车时按 `E` 触发逃犯追缉，小地图与战术全图会以金红菱形标出逃犯载具位置，摧毁即可赢取递增悬赏奖金与执法声望。

## 九、 全新像素赛博朋克 UI 与战术终端系统

游戏采用统一深空赛博紫-电青像素界面规范重新设计并整合全套交互界面：

- **主界面标题页**：全屏像素风霓虹特区天际线背景 + 发光霓虹字体标识，左侧 5 项垂直战术菜单支持一键续档/新开、`模式选择`三模式直达预览面板、`角色与车库`战前整备与 `设置选项`。
- **战斗实时 HUD**：
  - 左上角镶框主角像素头像、`Lv.` 等级与 `EXP` 条、红血/蓝甲/现金状态栏，并集成了 `[C]` 角色、`[L]` 任务、`[K]` 造物台、`车库` 快捷入口。
  - 右上角 **5★ 霓虹通缉星标条** 与脱战逃脱进度，下方搭配战术雷达小地图、GTA 式赛博任务追踪器（支持动态滚动与远距像素指针）及无尽模式可折叠波次卡。
  - 屏中左斜角 **悬浮连击计数（`连击 ×N`）**：沙盒/无尽模式连续击杀实时高亮。
  - 底部中央 **1–7 像素武器快捷栏**：7 把武器带独立像素枪械图标、按键号、实时弹药与一键切换/解锁跳转，右侧附带 `[B] 军械补给` 快捷按键。
- **7 合 1 战术指挥中枢（`M / L / C / B / K`）**：
  - **世界地图 `[M]`**：支持鼠标拖拽平移与滚轮/按钮缩放，左侧显示 **城区控制度（%）与繁荣星级**，底部支持一键 **快速传送** 七大城区磁悬浮站点与自定义折跃晶塔，右键/点击任意位置放置 GPS 航标。
  - **任务日志 `[L]`**：赛博情报联络官立绘加持，按 **主线任务 / 探索发现 / 世界动态** 分类追踪与接取/放弃任务，实时播报全城脉冲事件。
  - **角色 `[C]`**：全身赛博战甲立绘、属性汇总与 **战斗/机械/黑客/生存 4 大技能树、5 部位义体植入、三方阵营声望**。
  - **载具**：内置 **全部 10 款载具图鉴与像素造型展示**，支持现金购置后直接在玩家安全邻近坐标 **空投部署**，并可对当前驾驶/身旁载具直接进行三线改装升级、维修与 6 色涂装喷漆（含隐匿消星漆）。
  - **军械库 `[B]`**：7 类武器购买/弹药补充/三线升级、防弹护甲补充，并在无尽杀怪模式解锁 **泰坦/幻影战斗机甲、自动哨戒炮、轨道离子轰炸与空投主战坦克** 支援。
  - **造物台 `[K]`**：沙盒模式采矿资源仓库、基地建造（营火/壁垒/哨戒炮/折跃晶塔）、饰品装配、炼金合剂与世界 Boss 召唤。
  - **设置**：支持 **音乐/音效独立音量滑块**、**画质等级（高/中/低）**、**画面亮度（明亮昼夜/经典深邃）**、**动态天气后期滤镜开关**、**镜头震动开关**、HUD 精简与触控摇杆模式切换，配置自动持久化至本地，右侧附实时画质预览窗口。
- **暂停菜单（`Esc`）**：发光赛博对话框提供继续游戏、战术全图、随身军械、造物台/支援、设置选项、手动保存、返回出生点与返回主菜单。

## 十、 操作指南

### 键盘与鼠标（桌面端）
- **步行移动 / 全向驾驶**：`W A S D` 或 `方向键`
- **瞄准与开火（步行 / 机甲 / 车载扫射 / 坦克旋塔主炮 / 直升机机炮）**：`鼠标瞄准 + 左键` 或 `J`
- **切换武器**：`Q` 或数字键 `1`–`7`（或直接点击底部武器快捷栏）
- **机甲专属技能 / 载具手刹**：`空格 (Space)`
- **载具氮气加速**：`Shift`
- **上车 / 劫车 / 下车**：`F`
- **交互 / 挥镐采矿 / 营火折跃 / 进入地标 / 开启治安追缉**：`E`
- **战术全图（7 合 1 中枢）**：`M`
- **任务日志与世界动态面板**：`L`
- **随身军械库与机甲支援面板**：`B`
- **角色技能树 / 义体植入 / 声望面板**：`C`
- **赛博造物台（采矿合成 / 基地建造 / 饰品合剂 / 世界 Boss 召唤）**：`K`
- **黑客警讯干扰（需黑客 Lv.2）**：`H`
- **切换动态天气与屏幕后期滤镜**：`T`
- **切换 HUD 精简视野模式**：`V`
- **切换车载电台**：`R`
- **暂停 / 关闭中枢弹窗**：`Esc`

### 触屏端（移动/平板自适应双摇杆）
- **左摇杆**：步行移动 / 全向驾驶
- **右摇杆**：360° 瞄准与自动连发开火（同时支持步行、车载扫射、坦克炮塔旋转开火与直升机机炮）
- **右侧功能键**：随身军械/机甲、机甲技能、切枪、交互/改装/治安追缉、上车/下车、电台、刹车与氮气加速
